# Recall

**Recall** - приложение для создания карточек и запоминания информации с помощью интервального повторения.

Приложение позволяет создавать собственные карточки, распределять их по категориям, добавлять изображения и повторять материал в удобном темпе.

## Возможности

- Создание, редактирование и удаление карточек.
- Поиск карточек по вопросу и фильтрация по категориям.
- Добавление изображений к карточкам.
- Обучение с проверкой ответа.
- Интервальное повторение с учётом оценки пользователя.
- Автоматический расчёт времени следующего повторения.
- Сохранение истории повторений.
- Статистика обучения и отслеживание ежедневной цели.
- Календарь активности.
- Импорт и экспорт карточек в CSV.
- Светлая и тёмная темы оформления.

## Скачать и запустить

Готовая версия приложения доступна в разделе **Releases**.

1. Скачайте архив `Recall-v1.0.zip` из последнего релиза.
2. Распакуйте архив в удобную папку.
3. Запустите `Recall.exe`.

**Python и дополнительные библиотеки для запуска готовой версии устанавливать не требуется.**

## Запуск из исходного кода

Если вы хотите запустить приложение из исходного кода или внести изменения:

1. Склонируйте репозиторий:
   ```
   git clone <ссылка-на-репозиторий>
   ```
2. Перейдите в папку проекта:
   ```
   cd project_pyqt
   ```
3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```
   python main.py
   ```

## Технологии

- **Python** - основной язык программирования.
- **PyQt6** - создание графического интерфейса.
- **SQLite** - хранение карточек и истории повторений.
- **Qt Designer** - проектирование интерфейса.
- **QSS** - стилизация приложения.
- **PyInstaller** - создание исполняемой Windows-версии.

## Структура проекта

- `database/` - работа с базой данных SQLite.
- `dialogs/` - диалоговые окна приложения.
- `pages/` - страницы приложения.
- `ui/` - файлы интерфейса Qt Designer.
- `icons/` - иконки приложения.
- `styles/` - стили светлой и тёмной тем.
- `main.py` - точка входа в приложение.
- `paths.py` - работа с путями к ресурсам.

## Пример файла для импорта

В папке `examples/` находится файл `cards_for_demonstration_import.csv` с 10 готовыми карточками для демонстрации импорта.

**Примечание:** при импорте и экспорте CSV передаются только текстовые данные карточек. Изображения не экспортируются и не импортируются.
